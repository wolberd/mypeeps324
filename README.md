# Research Persons Tracker

A simple web application to keep track of important persons encountered during research. Built with vanilla HTML, CSS, and JavaScript.

## Features

- Add and manage people you meet during your research
- Store names, roles/titles, and notes for each person
- Clean, modern interface with responsive design
- Data persistence using localStorage
- No external dependencies required

## Usage

1. Open `index.html` in a web browser
2. Click the "+" button to add a new person
3. Fill out the form with the person's details
4. View all added persons in a grid layout
5. Delete persons using the delete button on each card

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - All styling and layout
- `script.js` - Application logic and functionality

## Getting Started

Simply clone this repository and open `index.html` in a web browser. No build process or installation required.
